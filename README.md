# School Collection Champion

Meu site se trata de um registrador de coletas de escola aonde cada sala ira registrar sua coleta, cada coleta gera pontos conforme a quantidade resgistrada e tera um ranking de sala com as pontuaçõs, nela tem que ter login por usuario e colocar a sua sala, tambem ter que ter o login de adm aonde ele ira gerenciar tudo
